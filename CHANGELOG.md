# Changelog

## 2.16.0 — 2026-08-18

- Добавлена дата окончания действия рядом с датой начала.
- Просроченные действия удаляются из цепочки после даты окончания.
- Для обоих полей даты выровнены размеры и стили текста.
- Добавлены проверки диапазона дат и совместимости JSON.

## 2.15.0 — 2026-08-18

- Дата начала действия перенесена в свернутую группу «Дополнительно».
- Добавлен UI-тест раскрытия дополнительных настроек.

## 2.14.0 — 2026-08-17

- В настройки действия добавлена дата начала с выбором через календарь.
- Повторения теперь рассчитываются от даты начала действия.
- Сохранена логика месячных дат и дней недели с выбором ближайшего подходящего дня.
- Добавлены unit- и UI-тесты.

## 2.13.0 — 2026-08-16

- Добавлен звуковой отсчёт последних трёх секунд для действий с автопереходом.
- В момент автоматического завершения сохраняется сигнал окончания через аудиопоток будильника.
- Добавлен regression-тест звуковых сигналов.

## 2.12.0 — 2026-08-16

- Добавлен индивидуальный автопереход к следующему этапу в настройках действия.
- Настройка сохраняется в JSON с обратной совместимостью.
- Добавлены unit- и UI-тесты.

## 2.11.0 — 2026-08-12

- Добавлена ручная генерация озвучки действий через Android TextToSpeech в редакторе цепочки.
- Озвучка сохраняется локально и воспроизводится при запуске действия.
- При изменении текста действие требует повторной генерации озвучки.
- Старая озвучка удаляется при снятии галочки или замене текста.
- Добавлено сохранение ключа озвучки в JSON с обратной совместимостью старых данных.
- Добавлены статусы генерации и regression-тесты кэширования.

## 2.10.11 — 2026-08-12

- Исправлено мерцание и краткое смещение экрана при навигации и раскрытии завершённых цепочек.
- Добавлен UI regression-тест стабильности контейнера системных отступов.

## 2.10.10 — 2026-08-10
