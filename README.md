# Routine Flow MVP

Минимальное Android-приложение для создания цепочек действий.

## Что уже есть

- создание цепочек;
- добавление действий в цепочку;
- порядок действий;
- повторения: каждый день, по будням, каждые 2 дня, раз в неделю;
- экран действий на сегодня;
- отметка выполнения;
- локальное хранение в файле `routine-flow.json`.

## Запуск

Открыть папку в Android Studio и дождаться синхронизации Gradle. Затем запустить на эмуляторе или телефоне с Android 8.0+.

На текущем окружении Android SDK и Gradle не установлены, поэтому локальная сборка здесь пока не выполняется. Android Studio установит или подключит необходимые компоненты.
